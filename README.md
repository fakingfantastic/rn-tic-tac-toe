# Tic Tac Toe 👋

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

## Technical Debt Conciderations

- Right now, we are assuming support for only 2 players. As such, logic liberties were taken:
  - Alternate from Player 1 to Player 2
  - Two Mark: X and O
